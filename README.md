# -BD-
包③在原版 1.0.5 基础上，把自定义方案做成可直接使用的 BD：方案可保存五个光环、四个法术及每个法术四组附魔（符文）与解锁标记，并出现在 BD 构筑页；成型模式一键装满整套（光环、法术、四组附魔全部装上，四槽强制全开 1111），成长模式进房后自动逐件发放、无需手动领取，光环与法术均匀穿插，法术到手带齐四组全开附魔；第四页签「方案编辑」可从全部 355 项光环、204 个法术（通用＋六角色专属）、174 个附魔（普通 / 精英 / 神话 / 星空分级）下拉挑选并按归属、等级筛选，方案可删除，准备界面只记录选择、进有效房间后才换装；成长发放节奏还可在「每间房一件」和「每三间房一件」之间切换并持久保存，同时修复了房间加载帧和过渡抖动导致同一间房被重复计数、提前发放的问题。
